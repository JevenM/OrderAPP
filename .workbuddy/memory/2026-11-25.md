## 交互与动效专项（v2.1.1）
用户 7 条：点菜页重构（三大类展开细分网格 + 订单状态流转）/ 历史订单详情原位放大 / 确认框回弹+完成态 / 头像左抽屉推动主页面 / 自绘日历 / 弹窗跑到底部的 bug / 三餐提交按钮形变。
- **根因**：`index.css` 里 `.overlay` 整条规则不存在（Portal 到 body 后没有 fixed 定位），弹窗变成普通块堆在页面末尾。补齐 `.overlay`/`.dialog-panel`/`.dialog-body` + overlay/dialog keyframes；Modal 默认 z=100、有 `.dialog-body` 独立滚动、进出场回弹、`origin` 参数走 WAAPI 从卡片原位缩放。
- **另一个连带 bug**：`html,body,#root { overflow-x: hidden }` 让 #root 成为滚动容器，顶栏/干饭分段条/点菜分类条的 sticky 全部失效。改 `overflow-x: clip`（+ @supports 回退）后恢复正常（用 CDP 实测 sticky top 55/136）。
- **ConfirmHost 重写**：view/open/done 分离，确认后原地变对勾停留 620ms 再 resolve，关闭期间保留内容防闪空。
- **OrderPage**：`lib/dishGroups.ts`（三大类 + 细分网格，选中收起并把筛选标签居中）；`lib/orderFlow.ts` + `cooking` 状态；顶部「TA 点的单」卡片（进度条 + 接单/开始制作/完成，乐观更新）；详情弹窗 `origin` 原位放大；删除补 useConfirm。App 里新增 `IncomingOrderNotify`（对方下单/我的单状态变更 → toast + browserNotify + ding）。
- **App 壳**：`.app-shell` / `.app-shell--pushed` + `.drawer` / `.drawer-scrim`；ProfileSheet 改成左侧抽屉（常驻挂载才有滑出动画），挂到 shell 外；点 scrim 复原。
- **DateField（新）**：`lib/calendar.ts` 月矩阵（周一起始、6×7 固定高）+ 自绘面板；floating 模式 fixed 定位 + 视口限位 + 上下翻转 + 滚动跟随（触发器出屏则收起）；已替换 MealLog / WeddingTopics / TimeCapsule / CouplePage 倒计时两处。
